# CleanerProUltra

تطبيق تنظيف وتحسين شامل لأجهزة Android

## المميزات
- تنظيف شامل للملفات غير المرغوب فيها
- تحسين النظام والأداء
- حماية من البرمجيات الخبيثة
- إدارة التطبيقات والملفات
- تحسين الألعاب
- مسح ضوئي للشبكة

./gradlew assembleDebug
